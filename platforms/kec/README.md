# Kuriosity Ecosystem Core (KEC)

KEC is a recognized KE platform identity.

Its capability mandate, exclusions, accountable owner, dependencies, release model, and product adoption relationship have not yet been ratified. This directory reserves the canonical platform location and shall not be interpreted as an admitted, released, or product-adoptable platform.

The [KEC mandate proposal](kec-mandate-proposal.md) prepares the required decisions. It remains Proposed, Pending, and non-effective.

The KE repository root represents the ecosystem and does not silently replace KEC.
