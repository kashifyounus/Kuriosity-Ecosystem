# Security Policy

## Reporting

Do not disclose suspected vulnerabilities, credentials, personal data, or restricted information in a public issue or pull request.

Use GitHub's private vulnerability-reporting or Security Advisory feature when it is available for this repository. If no private GitHub reporting option is visible, contact the repository owner through an already established private channel and provide only the information needed to investigate safely.

## Scope and Handling

Reports should identify the affected artifact or automation, version or commit, observed impact, reproduction evidence that is safe to share, and suggested containment. Receipt does not imply validation. The accountable security and repository authorities will classify, investigate, preserve evidence, coordinate remediation, and disclose only through an approved process.

Never include live secrets or unnecessary personal data in a report.
