# KE-TERM-001 — Canonical Terminology

| Term | Definition |
|---|---|
| KE | Kuriosity Ecosystem; the sole maintained ecosystem and engineering-governance authority |
| Ecosystem Authority | Human authority accountable for KE-wide governance |
| Platform | A reusable capability boundary admitted under KE |
| Product | A business-domain system that conforms to KE and may adopt platforms |
| Conformance | Evidence-backed satisfaction of a declared KE release and applicable instruments |
| Adoption | Explicit use of a versioned platform capability by a product |
| Extension | Product- or platform-owned addition that does not contradict adopted authority |
| Deviation | Approved bounded departure from an applicable rule |
| Authority | Legitimate power to create, approve, interpret, or supersede a governed obligation |
| Evidence | Durable, attributable information supporting a claim |
| Ratified | Formally approved by the authority required for a foundational instrument |
| Effective | Currently binding within declared scope |
| Historical | Retained for traceability; non-normative and not an active dependency |
| Retired | Removed from active use and authority after controlled disposition |
